# Iris Flower Machine Learning Analysis

Machine learning analysis of the Iris dataset using classification, clustering, and neural network techniques.

## Models & Techniques
- K-Nearest Neighbors (KNN)
- GridSearchCV for hyperparameter tuning
- K-Means Clustering
- Elbow Method
- Neural Network implemented from scratch
- ReLU and Softmax activation functions
- Backpropagation

## Technologies
Python • NumPy • Pandas • Scikit-learn • Matplotlib

## Project Overview
This project explores multiple machine learning approaches on the Iris flower dataset. It includes data preprocessing, supervised classification, unsupervised clustering, hyperparameter tuning, and the implementation of a neural network.

The complete analysis and implementation are available in the Jupyter Notebook.
